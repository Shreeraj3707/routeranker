## Data Contracts

Stage | Input | Output |

|—|—|—|

data_loader | raw GTFS .txt | cleaned DataFrames with arrival\_sec |
feature_engineering | cleaned DataFrames | 1 row per route × ~30 columns |
eda | route_features.csv | charts + rough_label column |
preprocessing | route_features_labeled.csv | X_*.npy, y_*.npy, scaler.pkl, encoder.pkl |
clustering | X_scaled.npy | kmeans.pkl, route_clusters.csv |
classification | X_train/test.npy | xgb.pkl, rf.pkl |
inference | all models + features | recommendations + simulation csv |
app | all csv/pkl | Streamlit UI |

## Runtime

Stage | BMTC (4,416 routes) |

|—|—|

data_loader | ~90 seconds |
feature_engineering | ~90 seconds |

clustering | ~15 seconds |
classification | ~30 seconds |
inference | ~5 seconds |
**Total** | **~4 minutes** |

## Extension Points

- **New city** → drop GTFS files in data/raw/<city>/, change one CITY

constant in data\_loader.py and feature\_engineering.py.

- **New feature** → add a column in build\_route\_features(); downstream

scripts pick it up automatically.

- **New model** → implement in a new src/<model>.py that reads X\_\*.npy,

writes a .pkl. Register in inference.py.

- **New dashboard tab** → add a with tabN: block in app.py.
